# Aurora CS Course Scheduler

The Aurora CS Course Scheduler is a React application that allows students to view computer science courses, track completed courses, and determine which courses they are eligible to take based on prerequisites.

## Project Locations

The application is organized into separate folders for each milestone.

- **Course Scheduler (Milestone 1):** Initial React application using JSON Server and localStorage.
- **Course-SchedulerM2 (Milestone 2):** Updated React application using Express and MySQL for course data and completion tracking.
- **Course-SchedulerM3 (Milestone 3):** In progress.

Each milestone folder contains its own README with installation instructions and information about running the application, where available.
